# OpenVINO on Aeon — builds, driver farm, upkeep

Task rules (devices, enable step, NPU pitfalls) = each Aeon host file (`claude/aeon/CLAUDE.md`, `codex/aeon/AGENTS*.md`); this file = configuration + upkeep, read on demand. Container `$HOME` = `/var/home/eturkes/debian` ⇒ `~/.local` ≠ the `/var/home/eturkes/.local/app` paths below.

- Builds, both with GenAI: host = `/var/home/eturkes/.local/app/openvino_genai` (glibc 2.43, host use, `setupvars.sh`); container = `/var/home/eturkes/.local/app/openvino_genai_container` (`ubuntu24` archive, glibc 2.38, under the container's 2.41). `intel-accel/env.sh` prepends the container build (`PYTHONPATH` + `LD_LIBRARY_PATH`) ahead of the inherited host `setupvars.sh` entries + exposes the GPU/NPU drivers (`LD_LIBRARY_PATH`, `OCL_ICD_VENDORS`, `ZE_ENABLE_ALT_DRIVERS`). Container build update → the target release's `ubuntu24` archive, `tar xzf … -C <dir> --strip-components=1`; a host OpenVINO update leaves it unchanged.
- Venv rule's why: the container Python lacks NumPy; the container build's compiled bindings cover Python 3.10–3.13; pip wheels carry their own RPATH.
- Hardware: GPU = Arc 140V (`xe`, `/dev/dri/renderD128`); NPU = AI Boost NPU 4 (`intel_vpu`, `/dev/accel/accel0`); nodes `nobody:nogroup` 0660, reached through `CAP_DAC_OVERRIDE`.
- `intel-accel` = user-local driver farm: host Intel drivers + a pinned container-compatible IGC (host IGC needs a newer glibc); generic libs (`libc`, `libtbb`) resolve from the container, `libstdc++` from the host (GPU driver needs `GLIBCXX_3.4.35`, container ships 3.4.33); `libnpu_driver_compiler.so` → `libopenvino_intel_npu_compiler_loader.so` (the Level Zero driver calls its `vcl*` API; the host symlink's monolithic compiler exports `CreateNPUCompiler` alone). OpenCL registers through the `OCL_ICD_VENDORS` dir (`OCL_ICD_FILENAMES` alone → error `-1001`), Level Zero through `ZE_ENABLE_ALT_DRIVERS`; GPU plugin = OpenCL + ICD + IGC, NPU plugin = Level Zero + compiler. Farm symlinks target `/run/host/...`, inert on the host. Remove = `rm -rf /var/home/eturkes/.local/app/intel-accel`.
- Upkeep: host Intel driver update → `python3 /var/home/eturkes/.local/app/intel-accel/make_farm.py`. Keep the pinned IGC on the host's IGC major line: compare `intel-accel/igc/libigc.so.2` with `/run/host/usr/lib64/libigc.so.2`; host higher → fetch the matching `github.com/intel/intel-graphics-compiler` release, `dpkg-deb -x` `intel-igc-core-2` + `intel-igc-opencl-2`, replace `intel-accel/igc/`, rebuild the farm. An IGC older than the GPU driver aborts the whole process, CPU + NPU work included, naming `command_stream_receiver.cpp`; `NEOReadDebugKeys=1 PrintDebugMessages=1` prints `Installed Compiler Library libigc.so.2 is incompatible`.
- Git tracks this file alone; the host-and-container-coupled `intel-accel` artifacts stay outside project repos.
