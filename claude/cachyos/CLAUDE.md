## Reading

- Reader gates: `permissions.deny` = pagers (`less`/`more`/`most`/`pg`), colorizers (`bat`/`batcat`/`ccat`/`pygmentize`/`highlight`/`source-highlight`) + TTY editors (`vi`/`vim`/`nvim`/`view`/`nano`/`emacs`/`ed`), matched in every Bash segment incl. pipes + compounds → reach those bytes with `Read`. Keep it Bash-only: a path-keyed `Read()` rule gates `Bash` by static command text and escalates unresolvable-cwd commands into a session-halting prompt under `bypassPermissions`. Bash output past `bashOutputMaxChars` (30000 default) spills to a file + 2 KB preview ⇒ a bounded command (`head -N`, `-c`, `sed -n`, `wc`, `jq '.x|length'`) beats a dump; whole-file reads → `Read`.
- `@path` (typed input + slash-command bodies) attaches the whole file <262144 B as a mention-time snapshot; `@path#L10-20` = that line range. Oversize + missing path = one silent no-attachment outcome → prove absence with `ls` before recording state absent.
- Text inside a binary (Claude CLI JS bundled into `~/.local/share/claude/versions/<v>`) → `/usr/bin/rg -a -o '<pat>.{0,400}'`; `-a` yields matching lines, while plain `rg` yields only `binary file matches`. `Read` returns mojibake → prefer `rg -a`; `strings`/`xxd`/`od` run free for byte-level questions `rg` leaves open. Widen `.{N}` on both sides to walk minified call sites.
- Structured files (JSON/arrays — permission/deny lists, lockfiles, manifests) → always prove content + disk shape before editing: `wc -c`; `jq '.<path>|length'`; `jq -r 'to_entries[]|"\(.key+1)|\(.value)"'` (ordinal lines survive intact); line count via `command grep -c ''` / `git show HEAD:<path> | wc -l`. Entry count/byte mismatch = partial view. Bash JSON can collapse to one markerless line + omit interior entries; later `Read`/`jq .` repeats it → editing that view deletes omitted entries; Read→Write minifies + truncates. Trust length + ordinal lines; reach exact bytes through anchored Edit; `git diff --stat` churn beyond intended edit = tell.
