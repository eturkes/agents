## Reading

- Reader gates: `permissions.deny` = pagers (`less`/`more`/`most`/`pg`), colorizers (`bat`/`batcat`/`ccat`/`pygmentize`/`highlight`/`source-highlight`) + TTY editors (`vi`/`vim`/`nvim`/`view`/`nano`/`emacs`/`ed`), matched in every Bash segment incl. pipes + compounds → reach those bytes with `Read`. Keep it Bash-only: a path-keyed `Read()` rule gates `Bash` by static command text and escalates unresolvable-cwd commands into a session-halting prompt under `bypassPermissions`. Bash output past `bashOutputMaxChars` (30000 default) spills to a file + 2 KB preview ⇒ a bounded command (`head -N`, `-c`, `sed -n`, `wc`, `jq '.x|length'`) beats a dump; whole-file reads → `Read`.
- `@path` (typed input + slash-command bodies) attaches the whole file <262144 B as a mention-time snapshot; `@path#L10-20` = that line range. Oversize + missing path = one silent no-attachment outcome → prove absence with `ls` before recording state absent. Dense markdown ≈3 B/token.
- Command economy: every run output rides the session → the quietest useful form: quiet/dot reporters (`pytest -q`, `cargo -q`, `make -s`, `bun --silent`, `curl -sS`; npm + pnpm defaults keep failure text, silent modes drop it); `--stat`/`--name-only` over full diffs; `-c`/`-l`/`--include` over bodies; `| head -N` on unbounded listings; tool-side filters over dumps. Bulk output → redirect + read a slice, or delegate. Pipes move rc to last stage → `set -o pipefail` or `${PIPESTATUS[0]}` when runner status matters.
- Text inside a binary (Claude CLI JS bundled into `~/.local/share/claude/versions/<v>`) → `/usr/bin/rg -a -o '<pat>.{0,400}'`; `-a` yields matching lines, while plain `rg` yields only `binary file matches`. `Read` returns mojibake → prefer `rg -a`; `strings`/`xxd`/`od` run free for byte-level questions `rg` leaves open. Widen `.{N}` on both sides to walk minified call sites.
- Structured files (JSON/arrays — permission/deny lists, lockfiles, manifests) → always prove content + disk shape before editing: `wc -c`; `jq '.<path>|length'`; `jq -r 'to_entries[]|"\(.key+1)|\(.value)"'` (ordinal lines survive intact); line count via `command grep -c ''` / `git show HEAD:<path> | wc -l`. Entry count/byte mismatch = partial view. Bash JSON can collapse to one markerless line + omit interior entries; later `Read`/`jq .` repeats it → editing that view deletes omitted entries; Read→Write minifies + truncates. Trust length + ordinal lines; reach exact bytes through anchored Edit; `git diff --stat` churn beyond intended edit = tell.
- Quote YAML frontmatter scalars opening with an indicator char (`[ { } ] , & * ! | > % @ # :`, backtick, double-quote): leading `[` → flow sequence → `ParserError` or silently-dropped field. Verify ad-hoc frontmatter with an ephemeral `pyyaml` parse.
- Context occupancy = latest assistant `usage` sum (input + cache create/read + output), often above transcript size because system/tools/CLAUDE overhead + redacted reasoning stay billed. Server-tool iterations (e.g. ToolSearch) stack cache-read by ~1 window/iteration → measure from an ordinary turn. `context-gauge` = sum; `jq .message.usage "$(context-gauge -p)"` = parts; effort shifts usage/stored ratio → remeasure. Window = 1M, MAIN + teammates. MAIN's = collapse-managed — the harness sheds content as it fills; a teammate compacts at last usage + pending payload > 967K (window - 33K), earlier under large payload or iteration inflation → target 950K + 17K reserve; discover tools early.
