# OpenVINO acceleration — Intel Lunar Lake

iGPU + NPU + CPU = enabled → **prefer OpenVINO for applicable local inference**. Container `$HOME` = `/var/home/eturkes/debian` ⇒ `~/.local` ≠ the `/var/home/eturkes/.local/app` paths below.

- **Run preference NPU > GPU > CPU.** NPU = dedicated AI silicon, best perf/W (default) · GPU = throughput + op/model fallback · CPU = universal correctness fallback.
- **Target a device by exact name (`"NPU"`)** → actual placement + loud failure on an unsupported model. `"AUTO:NPU,GPU,CPU"` = portability/fallback only: its own heuristics pick CPU even for an NPU-capable model, and code branching on the device string (device-conditional reshape/config/hints) reads `"AUTO:…"` as a distinct device → skips. Split one model across devices = `"HETERO:NPU,GPU,CPU"`.
- **NPU = static shapes only** → reshape every dynamic dim (batch → 1) before `compile_model`; exact `"NPU"` raises on a dynamic model, AUTO demotes it silently.
- **Dynamic *outputs* compile cleanly — NPU + GPU pad them.** The input reshape satisfies compile; a dynamic output dim (in-graph NMS, top-k) still returns the max-size buffer with unused rows padded, CPU alone keeping the true shape. GPU zero-fills; **NPU pad = uninitialized memory** → out-of-range values that pass validity filters and enter the data as real rows. Select rows by value (score, label sentinel); a row count reads pad as data. Qualify each dynamic-output model per device: compile + infer a zero tensor, diff shape + range vs CPU.
- **Confirm placement** → `compiled_model.get_property("EXECUTION_DEVICES")`; AUTO-selected devices report parenthesized (`['(CPU)']`). Return type splits: NPU = bare `str` (`'NPU'`), GPU/CPU = `list` (`['GPU.0']`, `['CPU']`) → membership-test the raw value (`"NPU" in v`), and normalize with `[v] if isinstance(v, str) else v` before indexing/iterating.
- **Enable before Python starts**: `source /var/home/eturkes/.local/app/intel-accel/env.sh` — the loader reads `LD_LIBRARY_PATH` at process start. It selects the container OpenVINO build (`PYTHONPATH` + `LD_LIBRARY_PATH`) + exposes the GPU/NPU drivers (`LD_LIBRARY_PATH`, `OCL_ICD_VENDORS`, `ZE_ENABLE_ALT_DRIVERS`).
- **Python = a project venv 3.10–3.13 with NumPy 2.x** (`uv venv --python 3.13 .venv && uv pip install numpy`): the container Python lacks NumPy + the compiled bindings cover 3.10–3.13. Keep `env.sh`'s `PYTHONPATH`; isolated modes (`-E`, `-I`, some `uv run` modes) drop it → there `uv pip install openvino openvino-genai` (wheels carry their own RPATH).
- Builds, both with GenAI: host = `/var/home/eturkes/.local/app/openvino_genai` (glibc 2.43, host use); container = `/var/home/eturkes/.local/app/openvino_genai_container` (`ubuntu24` archive, glibc 2.38, under the container's 2.41). `env.sh` prepends the container build ahead of the inherited host `setupvars.sh` entries. Replace it with the target release's `ubuntu24` archive, `tar xzf … -C <dir> --strip-components=1`; a host OpenVINO update leaves it unchanged.
- Self-test: `source /var/home/eturkes/.local/app/intel-accel/env.sh && <venv-python> /var/home/eturkes/.local/app/intel-accel/selftest.py` → names, compiles + infers on `CPU`, `GPU`, `NPU`.
- Hardware: GPU = Arc 140V (`xe`, `/dev/dri/renderD128`); NPU = AI Boost NPU 4 (`intel_vpu`, `/dev/accel/accel0`); nodes `nobody:nogroup` 0660, reached through `CAP_DAC_OVERRIDE`.
- `intel-accel` = user-local driver farm: host Intel drivers + a pinned container-compatible IGC (host IGC needs a newer glibc); generic libs (`libc`, `libtbb`) resolve from the container, `libstdc++` from the host (GPU driver needs `GLIBCXX_3.4.35`, container ships 3.4.33); `libnpu_driver_compiler.so` → `libopenvino_intel_npu_compiler_loader.so` (the Level Zero driver calls its `vcl*` API; the host symlink's monolithic compiler exports `CreateNPUCompiler` alone). OpenCL registers through the `OCL_ICD_VENDORS` dir (`OCL_ICD_FILENAMES` alone → error `-1001`), Level Zero through `ZE_ENABLE_ALT_DRIVERS`; GPU plugin = OpenCL + ICD + IGC, NPU plugin = Level Zero + compiler. Farm symlinks target `/run/host/...`, inert on the host. Remove = `rm -rf /var/home/eturkes/.local/app/intel-accel`.
- Maintenance: host Intel driver update → `python3 /var/home/eturkes/.local/app/intel-accel/make_farm.py`. Keep the pinned IGC on the host's IGC major line: compare `intel-accel/igc/libigc.so.2` with `/run/host/usr/lib64/libigc.so.2`; host higher → fetch the matching `github.com/intel/intel-graphics-compiler` release, `dpkg-deb -x` `intel-igc-core-2` + `intel-igc-opencl-2`, replace `intel-accel/igc/`, rebuild the farm. An IGC older than the GPU driver aborts the whole process, CPU + NPU work included, naming `command_stream_receiver.cpp`; `NEOReadDebugKeys=1 PrintDebugMessages=1` prints `Installed Compiler Library libigc.so.2 is incompatible`.
