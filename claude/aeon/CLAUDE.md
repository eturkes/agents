## Reading

- Reader gates: `permissions.deny` = pagers (`less`/`more`/`most`/`pg`), colorizers (`bat`/`batcat`/`ccat`/`pygmentize`/`highlight`/`source-highlight`) + TTY editors (`vi`/`vim`/`nvim`/`view`/`nano`/`emacs`/`ed`), matched in every Bash segment incl. pipes + compounds → reach those bytes with `Read`. Bash output past `bashOutputMaxChars` (30000 default) spills to a file + 2 KB preview ⇒ a bounded command (`head -N`, `-c`, `sed -n`, `wc`, `jq '.x|length'`) beats a dump; whole-file reads → `Read`.
- `@path` (typed input + slash-command bodies) attaches the whole file <262144 B as a mention-time snapshot; `@path#L10-20` = that line range. Oversize + missing path = one silent no-attachment outcome → prove absence with `ls` before recording state absent.
- Command economy: every run output rides the session → the quietest useful form: quiet/dot reporters (`pytest -q`, `cargo -q`, `make -s`, `bun --silent`, `curl -sS`; npm + pnpm defaults keep failure text, silent modes drop it); `--stat`/`--name-only` over full diffs; `-c`/`-l`/`--include` over bodies; `| head -N` on unbounded listings; tool-side filters over dumps. Bulk output → redirect + read a slice, or delegate. Pipes move rc to last stage → `set -o pipefail` or `${PIPESTATUS[0]}` when runner status matters.
- Text inside a binary (Claude CLI JS bundled into `~/.local/share/claude/versions/<v>`) → `/usr/bin/rg -a -o '<pat>.{0,400}'`; `-a` yields matching lines, while plain `rg` yields only `binary file matches`. `Read` returns mojibake → prefer `rg -a`; `strings`/`xxd`/`od` run free for byte-level questions `rg` leaves open. Widen `.{N}` on both sides to walk minified call sites.
- Structured files (JSON/arrays — permission/deny lists, lockfiles, manifests) → always prove content + disk shape before editing: `wc -c`; `jq '.<path>|length'`; `jq -r 'to_entries[]|"\(.key+1)|\(.value)"'` (ordinal lines survive intact); line count via `command grep -c ''` / `git show HEAD:<path> | wc -l`. Entry count/byte mismatch = partial view. Bash JSON can collapse to one markerless line + omit interior entries; later `Read`/`jq .` repeats it → editing that view deletes omitted entries; Read→Write minifies + truncates. Trust length + ordinal lines; reach exact bytes through anchored Edit; `git diff --stat` churn beyond intended edit = tell.
- Quote YAML frontmatter scalars opening with an indicator char (`[ { } ] , & * ! | > % @ # :`, backtick, double-quote): leading `[` → flow sequence → `ParserError` or silently-dropped field. Verify ad-hoc frontmatter with an ephemeral `pyyaml` parse.

## Subagents

- MAIN does the work: a planned unit's code, docs + config, debugging included, come from MAIN's own hand. A dispatch answers one trigger below through the role defined in `~/.claude/agents/` (repo `claude/agents/`), whose body carries the role's standing rules ⇒ a brief = task + finish line + paths + marker.
  - `reviewer` ← a diff or artifact ready for audit: each kernel-unit diff before its commit, every closing diff.
  - `consultant` ← a decision worth a second opinion: the phase plan at orientation close, a design fork whose reversal is costly, the second failed attempt on one problem.
  - `researcher` ← reading MAIN would only condense: web research, docs, changelogs, papers, forums, a large unfamiliar corpus or log set.
  - `operator` ← browser or desktop GUI interaction past a single fetch or capture (flows, settings, forms, logins); visual QA across UI states. Reading for sources = `researcher`.
  - `tester` ← a committed kernel contract: diff-blind red suite, differential oracle when the contract is a pure function.
  - `scientist` ← a scientific result, analysis or numerical method that needs independent reproduction.
  - `general-purpose` ← bulk per-item judgment behind a committed validator.
- Offload economics: `reviewer`, `consultant`, `tester` + `scientist` buy capability or independence at any size; `researcher`, `operator` + bulk buy MAIN context ⇒ they pay once the tokens kept out of MAIN ≫ brief + harvest; a few files or pages → MAIN reads them. Script-derivable facts (counts, spans, inventories, hashes) → MAIN computes. One teammate per question; a second, blind one where a wrong verdict is costly to reverse → MAIN takes the union of their findings. MAIN keeps working while teammates run.
- Security-vocabulary work (hardening audits, trust-gate reviews, vulnerability triage) stays on MAIN: the OpenAI request classifier ends any context holding that material (`Death shape`).

## Delivery

- Finish line first: a pasted body's `Met when`, else one you derive from the request + state in your first message. Run until it holds. Stops = `AskUserQuestion` whenever my input would improve the work (then continue with the answer), a blocker only I can clear, the finish line met. A message without a tool call ends the turn + halts work until I reply ⇒ status notes + recommendations ride with the next tool call, and a next step you name runs in that same message.
