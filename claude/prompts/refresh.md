# Refresh

Phase-flow repo on an older template. At the project root, run `cp ~/.local/app/agents/claude/CLAUDE.project.md CLAUDE.md`, start a fresh session, and paste everything below the rule. One session per repo.

---

This session moves the repo to the current phase-flow template and does nothing else. Upstream = `~/.local/app/agents` (`claude/CLAUDE.project.md` → this `CLAUDE.md`; global `CLAUDE.md` + `~/.claude/agents/` = the flow around it). Scope = the steps below + the checks that prove them; every other finding (bug, stale doc, improvement) becomes one `.agent/deferred.md` row with its acceptance check. Ask me whenever a step needs a ruling.

1. Orient. `cmp CLAUDE.md ~/.local/app/agents/claude/CLAUDE.project.md` → equal (else run the `cp` yourself + read the new file in full); `git status` = `CLAUDE.md` alone modified. Run `U=~/.local/app/agents; same() { git -C $U show "$1:claude/CLAUDE.project.md" | cmp -s - <(git show HEAD:CLAUDE.md); }; r=$(sed -n 's/.*last-sync = agents@\([0-9a-f]\{7,40\}\).*/\1/p' .claude/rules/upstream-sync.md 2>/dev/null | head -1); git -C $U cat-file -e "$r^{commit}" 2>/dev/null && { same "$r" && echo "recorded $r same" || echo "recorded $r differs"; }; git -C $U log --format=%h -- claude/CLAUDE.project.md | while read -r c; do same "$c" && { echo "match $c"; break; }; done`. `last-sync` = `recorded`, else `match` (the newest template commit equal to `git show HEAD:CLAUDE.md`); neither → ask me. `differs` = `CLAUDE.md` changed after the recorded sync without its rules pass → `last-sync` stays `recorded`, so the delta keeps every commit since; report `match` as the template it now holds. Upstream delta = `git -C ~/.local/app/agents diff <last-sync> HEAD -- claude/CLAUDE.project.md` + the commit bodies of `git -C ~/.local/app/agents log <last-sync>..HEAD -- claude/`. A line `git diff HEAD -- CLAUDE.md` removes outside that delta = repo law → fold it into its owning `.claude/rules/` file.
2. Obligations = every clause the delta adds or changes + every migration its commit bodies name. Per clause: this repo's practice follows it, or a `.claude/rules/` ruling keyed on that clause adapts, retires or marks it inapplicable (ask me where the choice is mine); a renamed or retired term → live law follows it; a changed `.agent/spec.md` layout → the spec follows it, preservation proven by script (unit ids before = unit ids after).
3. Live law = `.claude/rules/`, `.agent/spec.md`, `.agent/deferred.md`, docs, tools, tests + every executable check wherever it lives. History stays as written: `.agent/archive/`, decision records, `.agent/review.md` rows, commit messages. A rule that only restated retired mechanics → delete it.
4. Gates, tests + validators that parse spec sections, pin header text or name retired terms follow the change together with the text they pin; this body = my approval for exactly those edits. Each keeps its strength under the new layout and records its firing on a planted bad input before + after the edit.
5. `.claude/rules/upstream-sync.md` (its scope covers `CLAUDE.md`: an existing file keeps any wider `paths:` or bare tier; create it where absent with `paths: ["CLAUDE.md"]`): invariants = the current template's, recipe paths = `~/.local/app/agents`, one `last-sync = agents@<HEAD>` line for the upstream HEAD whose `claude/` bodies you read (a `claude/` commit landed since step 1 → its body joins the delta first), and the index of this repo's rulings keyed on template clauses.
6. Project `.claude/settings*.json` + `.claude/agents/`: an env pin or agent definition overriding the user-level models, effort or roles → remove it; ask me where its purpose is unclear.
7. Verify: the full gate green — the single command `.claude/rules/` records, else every gate invocation it lists, each run + named; a check that fails the same way at the pre-refresh `HEAD` (in a worktree) = pre-existing → one `.agent/deferred.md` row each + named in the gate result. `rg --hidden -g '!.git' -n -e 'last-sync = agents@' -e <each retired term the delta names>` from the repo root → every live-law hit justified, beside its positive controls: the `.claude/rules/upstream-sync.md` hit + a history-path hit. A fresh `claude -p --output-format stream-json --verbose "Answer from the context loaded at session start, else reply NOT LOADED: <a question only spec.md answers>" < /dev/null` answers it with zero tool calls; one `reviewer` over the whole diff on lenses fixed before reading — every obligation met or carried by a named ruling, nothing lost from `.agent/spec.md`, each edited check as strong as before, `CLAUDE.md` = the template byte for byte.
8. One commit: subject `<scope>: template agents@<last-sync> behind upstream → refreshed to agents@<new>`; body = upstream range, each obligation + how it was met or ruled, gate result, the reviewer's verdict.

Met when: `CLAUDE.md` equals the template byte for byte, every obligation is met or carried by a named `.claude/rules/` ruling, the full gate passes on a clean working tree at the refresh commit (each pre-existing failure carried by its `.agent/deferred.md` row), and the final message lists each obligation with how it was met, the files changed per step, the gate result with its pre-existing failures, skipped, not-run + missing checks named or `none`, the `claude -p` result, each teammate by name + role + verdict, the `.agent/deferred.md` rows added, each advisor call with your ruling (or `none`), what you could not confirm, the `git status` result, and the commit SHA.
