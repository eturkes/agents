# Refresh

Phase-flow repo on an older template. At the project root, run `cp ~/.local/app/agents/claude/CLAUDE.project.md CLAUDE.md`, start a fresh session with `--effort xhigh`, and paste everything below the rule. One session per repo.

---

This session migrates the repo to the current phase-flow template and does nothing else. Upstream = `~/.local/app/agents` (`claude/CLAUDE.project.md` → this `CLAUDE.md`; global `CLAUDE.md` + `~/.claude/agents/` = the flow around it). Scope = the steps below + the checks that prove them; every other finding (bug, stale doc, improvement) becomes one `.agent/deferred.md` row with its acceptance check and waits for a later session. Ask me whenever a step needs a ruling.

1. Orient. `cmp CLAUDE.md ~/.local/app/agents/claude/CLAUDE.project.md` → equal (else run the `cp` yourself + read the new file in full); `git status` = `CLAUDE.md` alone modified. `last-sync` = the upstream commit whose template equals `git show HEAD:CLAUDE.md`: `git -C ~/.local/app/agents log --format=%h -- claude/CLAUDE.project.md | while read -r c; do git -C ~/.local/app/agents show "$c:claude/CLAUDE.project.md" | cmp -s - <(git show HEAD:CLAUDE.md) && { echo "$c"; break; }; done` (a recorded value may be stale). Upstream delta = `git -C ~/.local/app/agents diff <last-sync> HEAD -- claude/CLAUDE.project.md` + the commit bodies of `git -C ~/.local/app/agents log <last-sync>..HEAD -- claude/`. A line `git diff HEAD -- CLAUDE.md` removes outside that delta = repo law → fold it into its owning `.claude/rules/` file.
2. `.agent/spec.md`: `Deferred` → `Tasks`, the checklist the template's `Session flow` defines — each unfinished unit = one `- [ ]` row in spine order, keeping its acceptance check + binding notes as indented sub-bullets; a note that rules rather than tracks → `Decisions`; last line = the `.agent/deferred.md` pointer. Prove preservation by script: the unit ids of the old section = the unit ids of the new one.
3. Live law → current vocabulary, across `.claude/rules/`, `.agent/spec.md`, `.agent/deferred.md`, docs, tools, tests + every executable check wherever it lives (`.agent/decisions/` validators included): dispatch roles `map`/`res` → `researcher` or MAIN, `spike` + `triage` → MAIN, `test`/`orc` → `tester`, `prod` → `general-purpose`, `rev` → `reviewer`, `advisor` → `consultant`; solo licences, `Subagents` b1/b2 + the per-unit dispatch line → global `Subagents` triggers + commit bodies naming each teammate the unit used (name, role, verdict); `gpt-6-luna` teammates + 887K/920K budgets → `gpt-6-astra` + 272K; `CLAUDE_CODE_EFFORT_LEVEL` + thinking-depth lines → `--effort` at launch; Explore/Plan agents → off; `/goal` bodies → pasted prompts; template path → `~/.local/app/agents/claude/CLAUDE.project.md`. A rule that only restated retired mechanics → delete it. History stays as written: `.agent/archive/`, decision records, `.agent/review.md` rows, commit messages.
4. Gates, tests + validators that parse spec sections, pin header text or name retired terms follow the rename together with the text they pin; this body = my approval for exactly those edits. Each keeps its strength under the new layout (open units = `- [ ]` rows; `- [x] <sha>` rows legal until phase close) and records its firing on a planted bad spec before + after the edit.
5. `.claude/rules/upstream-sync.md` (create it where absent, `paths: ["CLAUDE.md"]`): invariants = the current template's, recipe paths = `~/.local/app/agents`, `last-sync = agents@$(git -C ~/.local/app/agents rev-parse --short HEAD)`.
6. Project `.claude/settings*.json` + `.claude/agents/`: an env pin or agent definition overriding the user-level models, effort or roles → remove it; ask me where its purpose is unclear.
7. Verify: the full gate command green; `rg` over the live-law paths for the retired vocabulary of step 3 → no hit you cannot justify as a non-role use, beside a positive control on a history path; a fresh `claude -p --output-format stream-json --verbose "<a question only spec.md answers>"` answers with zero tool calls; one `reviewer` over the whole diff on lenses fixed before reading — nothing lost from `Deferred` → `Tasks`, each edited check as strong as before, live law free of retired vocabulary, `CLAUDE.md` = the template byte for byte.
