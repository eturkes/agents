# Refresh

Use: a phase-flow repository on an older template, one session per repository. At the project root: copy in the template files (README `Template files`) → fresh session → paste everything below the rule.

---

This session moves the repo to the current template. The template files are copied in, uncommitted: `CLAUDE.md`, `.claude/agents/*.md`, `.agent/spec-lint`; the delta = their `git diff HEAD`. Scope = the steps below + the checks that prove them; every other finding (bug, stale doc, improvement) becomes one `.agent/deferred.md` row with its acceptance check. Ask me whenever a step needs a ruling. A `.claude/rules/` ruling keyed on the clause a step enforces = my ruling for that step → the step works what the ruling leaves open, the commit body naming it.

1. Orient. `git status` = the template files alone modified or added, else ask me; read the new `CLAUDE.md` in full + the whole delta (`git diff HEAD -- CLAUDE.md .claude/agents .agent/spec-lint`, new files included). A unit branch awaiting landing (each linked worktree's branch in `git worktree list` + each branch the resume note names) whose landing would revert the refresh (an exact-tree landing does) → ask me before editing.
2. Obligations = every clause the delta adds or changes. Per clause: this repo's practice follows it, or a `.claude/rules/` ruling keyed on that clause adapts, retires or marks it inapplicable (ask me where the choice is mine); a term, path or value the delta renames, changes or retires → live law follows it, its obligation recording the old form; a changed `.agent/spec.md` layout → the spec follows it, preservation proven by script (unit ids before = unit ids after). A line the delta removes that held this repo's own law (a local edit to the old copy) → its owning `.claude/rules/` file; a role file the template does not ship = the repo's own → kept.
3. Live law = `.claude/rules/`, `.agent/spec.md`, `.agent/deferred.md`, docs, tools, tests + every executable check wherever it lives. History stays as written: `.agent/archive/`, decision records, `.agent/review.md` rows, commit messages. A rule that only restated the template or retired mechanics → delete it. `.claude/rules/upstream-sync.md` (a retired sync record) → each ruling it alone holds moves to its owning rule file; the file goes.
4. Gates, tests + validators that parse spec sections, pin header text or pin an old form step 2 recorded follow the change together with the text they pin; this body = my approval for exactly those edits. Each keeps its strength and records its firing on a planted bad input before + after the edit. The gate command runs `.agent/spec-lint`.
5. Portability (`CLAUDE.md` `Authoring`): live law points at nothing outside the repo — home paths, other repos, machine-specific tools; a hit → a repo-relative form, else ask me. Project `.claude/settings*.json`: an env pin of models or effort → remove it; ask me where its purpose is unclear.
6. Verify: the full gate green — the single command `.claude/rules/` records, else every gate invocation it lists, each run + named; a gate check that grades committed history → the full gate runs at step 8 instead, on the commit; a check that fails the same way at the pre-refresh `HEAD` (in a worktree) = pre-existing → one `.agent/deferred.md` row each + named in the gate result. `rg --hidden -g '!.git' -n -F -e <each old form step 2 recorded> .` from the repo root → every live-law hit justified, beside a positive control: a history-path hit, else the old form's hit in the pre-refresh tree (`git grep -n -F -e <old form> HEAD`). A fresh `claude -p --output-format stream-json --verbose "Answer from the context loaded at session start, else reply NOT LOADED: <a question only spec.md answers>" < /dev/null` answers it with zero tool calls.
7. After step 6, review the whole diff, its `.agent/deferred.md` rows included, on lenses fixed before reading — every obligation met or carried by a named ruling, nothing lost from `.agent/spec.md`, each edited check as strong as before.
8. One commit, taking every change; its body records a full-gate run on that commit's tree. Every gate check reads the working tree alone → commit after the gate's last run on the final working tree (that run = the commit's tree). A gate check grades committed history (e.g. replays the suite at each commit of a range) → it sees the refresh commit only once that commit exists: commit first, run the full gate on it, then amend the message alone to record the result (`git rev-parse HEAD^{tree}` equal before + after); a failure → fix, amend the tree, rerun. Subject `<scope>: template behind → refreshed (<the delta in a phrase>)`; body = each obligation + how it was met or ruled, that gate result, the review verdict.

Met when: the template files stand in the refresh commit exactly as copied in, every obligation is met or carried by a named `.claude/rules/` ruling, and the full gate passes on the refresh commit's tree (step 8's run; each pre-existing failure carried by its `.agent/deferred.md` row).
